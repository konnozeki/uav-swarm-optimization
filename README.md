# UAV Swarm Optimization — Checkpoint 01

Checkpoint 01 establishes the base optimization model and evaluation pipeline.

## Scope

- 2D UAV formation model
- weighted sensing coverage
- redundancy
- communication connectivity
- collision constraints
- basic scenario generation
- baseline solvers: Random Search, Connected Greedy, Vanilla GA

This checkpoint is intentionally simple. Graph-aware operators, ablation,
statistical benchmarking, and formation-transition optimization are introduced
in later checkpoints.
