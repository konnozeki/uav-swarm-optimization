# Checkpoint 01 — Model, metrics, and baselines

## Question

Can the UAV swarm formation problem be modeled, evaluated, and solved with
simple baselines before adding graph-aware mechanisms?

## Components

- Scenario and solution representation
- Coverage, redundancy, connectivity, collision, and feasibility metrics
- Scalar objective for common baseline comparison
- Random Search
- Connected Greedy
- Vanilla Genetic Algorithm
- Basic scenario generation and visualization

Checkpoint 01 is the modeling and baseline foundation for the later graph-aware
and transition-aware checkpoints.
